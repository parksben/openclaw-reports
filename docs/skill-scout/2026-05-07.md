## 1. Proactive Agent（主动型 Agent 架构 🦞）

**链接：** https://clawhub.ai/halthelobster/proactive-agent

**功能描述：**
@halthelobster（Hal Labs）出品，下载量 154k，⭐ 744，刚刚更新至 v3.1.0。定位为"Hal Stack"核心组件，将 Agent 从被动响应转变为主动型 AI 伙伴。三大支柱：**Proactive（主动）**——会主动反向提问、发现用户未想到的需求；**Persistent（持久）**——WAL（Write-Ahead Logging）协议确保关键信息在上下文压缩前先写入，Working Buffer 防止对话截断期间数据丢失；**Self-improving（自进化）**——内置安全演进护栏（ADL/VFM 协议），10 次尝试失败前不向用户求助。v3.1.0 新增 Autonomous vs Prompted Crons 区分（systemEvent 与 agentTurn 分别适用自主定时和指令触发）、工具迁移清单。

**适用场景：**
- 构建一个"会主动帮你想"而不只是等待指令的 Agent
- 长期对话场景下防止上下文丢失（WAL 协议 + Compaction Recovery）
- 自动化巡检 cron：Agent 定期检查状态并主动联系用户报告异常
- 与 Self-Improving Skill 组合，构建自主进化的 Agent 基础架构
- 需要高可靠性、防崩溃的生产级 Agent 系统

## 2. AdMapix（广告情报 & 应用市场分析）

**链接：** https://clawhub.ai/fly0pants/admapix

**功能描述：**
@fly0pants 出品，下载量 127k，⭐ 275，21 小时前更新。通过 AdMapix API 提供广告创意情报与移动应用分析能力：搜索竞品广告素材（视频/图文/H5）、分析 App 下载量与收入趋势、查看应用商店排名、追踪投放天数与曝光量。支持中英文双语自动切换（中文走万/亿格式，英文走 K/M/B 格式）。需配置 `ADMAPIX_API_KEY`（官网免费注册可获取）。数据免责：下载量和收入为第三方估算。

**适用场景：**
- 竞品广告监控：搜索同类 App 的主流广告创意类型和投放策略
- 出海应用市场分析：查看目标品类在各地区的排名与下载趋势
- 广告投放前调研：了解竞品的广告素材形式偏好（视频 vs 图文）
- 应用营收评估：估算竞品 App 的月收入和用户规模
- 结合 Multi Search Engine 做竞品全方位情报收集

## 3. PollyReach（AI 电话助理 🦜）

**链接：** https://clawhub.ai/pollyreach/pollyreach

**功能描述：**
@pollyreach 出品，下载量 96.8k，⭐ 39，6 天前更新。给 Agent 配备一个真实电话号码，让 AI 能代替人类完成电话任务：自动查找目标联系方式、研究办事流程、拨出电话并完成任务。支持代订餐厅/酒店、联系客服、批量安排面试电话，以及接听来电、过滤骚扰电话、充当 7×24 AI 前台。接听规则完全可自定义（"作为我的助理接电话"）。

**适用场景：**
- 让 Agent 帮你预约餐厅、诊所、政府办事处（无需你亲自打电话）
- 批量外呼场景：招聘初筛电话、客户回访通知
- 个人 AI 秘书：设置来电过滤规则，屏蔽陌生推销电话
- 商务谈判辅助：Agent 先电话确认信息，再汇报给你
- 7×24 AI 客服前台：自动接听并记录来电需求

## 4. Obsidian（Obsidian 笔记库自动化）

**链接：** https://clawhub.ai/steipete/obsidian

**功能描述：**
@steipete 出品，下载量 90.7k，⭐ 371，v1.0.0，刚刚更新。通过 `obsidian-cli` 让 Agent 完整操控 Obsidian 笔记库（Vault）。核心功能：在所有 Vault 中搜索笔记名称或内容（`search` / `search-content`）、创建新笔记（含内容与自动打开）、安全移动/重命名笔记（同步更新全库 `[[wikilinks]]`，这是相比直接 `mv` 的核心优势）、删除笔记。通过读取 Obsidian 配置文件自动解析当前活跃 Vault，无需硬编码路径。需要安装 `obsidian-cli`（`brew install yakit`）。

**适用场景：**
- 会议/通话结束后，Agent 自动将纪要写入 Obsidian 笔记
- 定时整理笔记：把散落的 daily notes 汇总为周报笔记
- 全库语义搜索：用自然语言找到相关笔记后进行内容提取
- 安全重构知识库：批量重命名笔记时自动更新所有引用链接
- 配合 Self-Improving Agent 使用：将学习记录同时写入 Obsidian 和结构化记忆层
