## 汇率计算公式

以 1 美元 = X 人民币为基础：

- **美元兑人民币：** `USD/CNY = rates["CNY"]`
- **欧元兑人民币：** `EUR/CNY = rates["CNY"] / rates["EUR"]`
- **英镑兑人民币：** `GBP/CNY = rates["CNY"] / rates["GBP"]`
- **日元兑人民币（百日元）：** `JPY/CNY = rates["CNY"] / rates["JPY"] × 100`
- **港币兑人民币：** `HKD/CNY = rates["CNY"] / rates["HKD"]`
