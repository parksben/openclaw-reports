## 计算方式

所有汇率基于 ExchangeRate-API 提供的美元基准汇率换算得出：

- **USD/CNY** = rates\["CNY"\] = 6.79
- **EUR/CNY** = rates\["CNY"\] / rates\["EUR"\] = 6.79 / 0.874 ≈ 7.77
- **GBP/CNY** = rates\["CNY"\] / rates\["GBP"\] = 6.79 / 0.755 ≈ 8.99
- **JPY/CNY（百日元）** = rates\["CNY"\] / rates\["JPY"\] × 100 = 6.79 / 161.61 × 100 ≈ 4.20
- **HKD/CNY** = rates\["CNY"\] / rates\["HKD"\] = 6.79 / 7.84 ≈ 0.8661
